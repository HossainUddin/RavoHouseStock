Google Sheets & Apps Script Setup

Follow these 4 simple steps to connect this website to your personal Google Sheets database:

  1. Step 1: Create a Google Spreadsheet
    Go to sheets.google.com, create a new spreadsheet named RAVO HOUSE Database.
  2. Step 2: Open Apps Script
    Inside your spreadsheet, click Extensions > Apps Script.
  3. Step 3: Copy Backend Code
    Replace any existing code in Code.gs with the code inside the project folder backend/Code.gs. Run setupDatabase() once to create all sheets.
  4. Step 4: Deploy as Web App
    Click Deploy > New deployment > Web app.
    • Execute as: Me
    • Who has access: Anyone (crucial for web access)
    Copy the generated Web App URL and paste it in the Settings tab!
GitHub Pages Hosting:

Commit and push these files to a GitHub repository, go to Settings > Pages > Branch: main, and your website will be live in 60 seconds!
